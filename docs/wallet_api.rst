Wallet API Functions
====================

Low-level functions for signed account endpoints (balances, snapshots, account trades, margin).
Used internally by the :doc:`Wallet <wallet>` class. Credentials are managed by
``panzer`` (``~/.panzer_creds``); see :doc:`secrets`.
